为什么这一版能用

之前的 APP 套的是安卓自带的 WebView，它没有朗读功能。
这一版改用 Chrome / Edge 内核，和你现在用浏览器打开是同一套引擎，所以朗读正常。

安装后

1

手机上要有 Chrome 或 Edge（弟弟已经有 Edge 了）

2

点桌面图标打开，首次可能需要选一个浏览器，选 Edge 或 Chrome

3

进英语页点句子，应该能正常朗读

如果打开后发现顶部有一条地址栏，那是正常的。因为站点验证还在配置中，暂时没有做到完全全屏，功能不受影响。

和网页版的关系

这个 APP 打开的就是同一个网页，数据完全共用。
已有的打卡记录不会丢。
