这一步最关键

没声音不是软件坏了，是手机还没给语音权限。按第三步开一次，以后就一直好用了。

装好后按顺序做

1

先打开设置，顶部搜索框输入 文字转语音（小米也叫 TTS）

2

进去后看首选引擎，选中一个（小艺 / 华为语音引擎 / Google 文字转语音都行），再点 安装语音数据，把英语下载下来

3

回到设置，进 应用管理 → 莫欺少年 → 权限，把语音相关权限打开。
如果设置里没有语音权限项，就装一个 Edge 浏览器打开一次任意网页，系统会自动弹出语音授权，点允许即可 —— 这是最快的办法。

4

打开莫欺少年，进英语页，点句子试听。还是没声音就点最下面的 「朗读没声音，点这里自检」，把弹窗截图发给家长。

装新包提示签名冲突？先卸载旧版再装。卸载前进 App 看一眼本月打卡天数，记下来，不然本地记录会清掉。

数据说明

打卡记录、答题进度都存在手机本地，不上传、不联网也能用。换手机或卸载重装会清空。
